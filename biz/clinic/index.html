Справка по клинике

Пришло письмо о повышении цен? Выберите клинику: справка покажет, как она изменила свой публичный прайс за год, и сравнит с рынком Москвы, Росстатом и прогнозами инфляции.

Пересчитать с вашими весами услуг — расчёт идёт в браузере, веса никуда не отправляются

По умолчанию — веса корзины Росстата по Москве. Если у клиники нет какой-то позиции, веса остальных пересчитываются к 100%. Рынок тоже пересчитывается по вашим весам.

Ограничения

    Скоро в справке

    • Рост цен клиник того же округа.
    • Справка по Санкт-Петербургу, Ростову-на-Дону и Уфе: витрина цен там уже есть, для роста цен нужно больше клиник с прайсом годичной давности и Росстат по региону.
    • Уведомление, когда клиника обновит прайс на сайте, и фактический рост против процента из письма.
    • Сверка вашего договорного прайса с публичным: файл не покидает ваш компьютер (как это устроено).
